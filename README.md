# Income Band Classifier

A machine-learning and Streamlit project that classifies Adult-schema records into `<=50K` or `>50K` income bands. It does not estimate an exact salary.

## What it demonstrates

- A scikit-learn pipeline with numeric imputation and categorical one-hot encoding.
- A reproducible stratified train/test split and random-forest baseline.
- Raw-feature consistency between training, single-record inference and CSV batch inference.
- Local model persistence and an exported evaluation report.

## Run

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python train.py /path/to/adult.csv
.venv/bin/streamlit run app.py
```

The CSV must include `age`, `hours-per-week`, `education`, `occupation` and `income`. Categorical `?` entries are treated as missing. Only load joblib files produced locally from trusted source.

## Portfolio preparation

The original app used five inputs that did not match the numeric training feature set. The public app now shares four explicit input fields with a fitted preprocessing pipeline. `exploration.ipynb` retains the output-cleared historical experiments; use `train.py` as the runnable training entry point. Historical app-generation cells were removed to keep the maintained app intact.

Dataset rows and fitted pickle artifacts are excluded. Supply a dataset you are authorized to use, retain its source/license locally, and inspect the evaluation JSON generated by your own run.

## Limitations

Historical demographic data can encode substantial bias. This educational baseline is unsuitable for hiring, compensation or eligibility decisions. A held-out result on this dataset does not establish generalization to current salaries or a new population. No production accuracy is claimed.
